# 🚀 Featured Data Analytics Project

## 🏦 Banking Analytics Dashboard

**End-to-End Data Analyst Project | MySQL + SQL + Python/EDA + Power BI + DAX**

An interactive banking analytics solution built to analyze **customers, loans, deposits, account balances, customer segments, and engagement**.

### 🔄 Project Pipeline

```text
Banking Dataset
      ↓
MySQL
      ↓
SQL Analysis & Validation
      ↓
Data Cleaning & Transformation
      ↓
Python EDA
      ↓
Power BI Data Model
      ↓
DAX Measures & KPIs
      ↓
Interactive Dashboard
      ↓
Business Insights & Recommendations
```

### 📌 Key Metrics

| KPI | Value |
|---|---:|
| 👥 Total Clients | 2,940 |
| 💰 Total Loan | $4.38B |
| 💵 Total Deposit | $3.77B |
| 🏦 Bank Loan | $1.77B |
| 💼 Business Lending | $2.60B |
| 💳 Credit Cards | $9.53M |
| 💸 Total Fees | $158.19M |
| 💰 Bank Deposit | $2.01B |
| 🏧 Checking Account | $963.28M |
| 💵 Saving Account | $698.73M |
| 🌍 Foreign Currency | $89.65M |

### 📊 Dashboard Pages

**01 — Home**  
Executive overview with customer and financial KPIs.

**02 — Loan Analysis**  
Loan portfolio analysis by banking relationship, income band, nationality, and engagement.

**03 — Deposit Analysis**  
Deposit and account analysis across income bands, nationalities, account types, and engagement.

**04 — Summary**  
Consolidated executive-level view of the most important banking KPIs.

### 🧠 Business Questions Answered

- Which customer segments contribute the most loan value?
- How is the loan portfolio distributed across banking relationships?
- How are deposits distributed across income bands?
- Which nationalities contribute the largest loan and deposit balances?
- What account types hold the largest customer balances?
- How does customer engagement relate to lending and deposits?
- Where are potential cross-selling opportunities?

### 💡 Example Business Insights

- The overall loan portfolio is approximately **$4.38B**.
- Business lending represents approximately **$2.60B**, making it a major component of the lending portfolio.
- Total deposits are approximately **$3.77B**.
- Customer balances are distributed across checking, savings, foreign currency, and other account types.
- Segmenting customers by income, nationality, banking relationship, and engagement helps identify higher-value customer groups.
